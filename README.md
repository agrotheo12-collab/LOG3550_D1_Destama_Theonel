LOG3550 — Devoir 1 : Catalogue de livres

Description du projet

Cette application web permet de consulter et de gérer un catalogue de livres à travers une interface simple et responsive.

Fonctionnalités

* Affichage des livres sous forme de cartes.
* Recherche de livres.
* Filtrage par catégorie.
* Tri des livres.
* Ajout de livres à l’aide d’un formulaire.
* Interface responsive adaptée aux téléphones, tablettes et ordinateurs.

Technologies utilisées

* HTML5
* CSS3
* JavaScript

1. Cloner ou télécharger le dépôt GitHub.
2. Ouvrir le dossier du projet.
3. Ouvrir index.html dans un navigateur web.
